tesmartctl

Your TESmart KVM/HDMI Switch now unleashed

REST API, floating kit, full panel, Hubitat, and CLI for TESmart 8- and 16-port HDMI / KVM switches over LAN or RS232.

Install from PyPI GitHub Hubitat 
# install / upgrade from PyPI
# core only — add [mdns] , [serial], or [kit] if needed
pip install -U tesmartctl
# To install the server: Use the walk thru install
tesmartctl install
# Start the server: use the quickstart option after install
tesmartctl quickstart
# Connect client: floating kit via mDNS
# or open /panel in a browser
tesmartctl --via auto kit

Floating HDMI Switch Kit Demo

Interactive demo — same UI as tesmartctl kit. Try size, colour, brightness, auto-dim, names, hiding a disabled input, and Hubitat-style banners (from on the status line).
