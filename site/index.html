tesmartctl

Your TESmart switch, your controls

REST API, floating kit, full panel, Hubitat, and CLI for TESmart 8- and 16-port HDMI / KVM switches over LAN or RS232.

Install from PyPI GitHub Hubitat 
pip install -U tesmartctl
tesmartctl listen --http --panel

Floating HDMI Switch Kit Demo

Interactive demo — same UI as tesmartctl kit. Try size, colour, and Hubitat-style banners.

How it connects

One listener owns the switch session and fans out to every client you already use.
